# 菓暦（かれき）― 和菓子の図鑑

どら焼き・大福などの定番、毎月の季節の和菓子、上生菓子を食べるたびに記録して、**定番30種の図鑑**と**季節の12か月の図鑑**を埋めていくスマホ向け Web アプリ（PWA）です。行った和菓子屋には地図の上に判子が押され、毎月の「お題」（その月のモチーフ5つ）を集めるスタンプラリーになっています。

**使ってみる：** https://shisakulab.github.io/kareki/ （スマホで開いて「ホーム画面に追加」するとアプリのように使えます）

**紹介記事（note）：** https://note.com/shisaku_lab/n/n1e702bd2c0d0

データ（記録・写真・位置）は端末の中（IndexedDB）にだけ保存し、どこにも送りません。写真は保存するときに縮めて描き直すので、撮影場所などの情報は消えます。

## 使い方
- **地図（ホーム）**：行った店は、季節の色の判子で表示されます。字はその店で最後に集めたモチーフ、数字は通った回数です。店の近く（150m 以内）で記録したことがある店は、判子の縁が二重になります。地図を長押しすると店を追加できます
- **近くの和菓子屋**：ズーム 14 以上で、まだ立ち寄っていない和菓子屋が点線の丸で出ます。アプリを開いているあいだ、300m 以内に店があると画面の上に距離と方向が出て、50m 以内に入ると「立ち寄って判子を押す」が押せます（位置を確かめて押すので、その場にいないと押せません）。店は OpenStreetMap の名前から選んでいるので、違う店や抜けがあります。閉店していた店は外せます
- **右下のボタン**：虫めがねで店名から和菓子屋を探せます（全国のデータと自分で追加した店。近い順）。その下のボタンで現在地に戻り、歩くと地図がついてきます（地図を指で動かすと止まります）
- **今月のお題**：画面の上にあるカードに、その月のお題が5つ並びます。旬や行事の季節の和菓子4つ（10月なら栗きんとん・栗蒸し羊羹・芋ようかん・栗饅頭）と、上生菓子の枠1つです。記録した品名から季節の和菓子が自動で当てはまり、判子が押されて、5つそろうと「満願」になります
- **＋（記録）**：写真・品名・店・日付・上生菓子の題材・点数（0.0〜5.0）・感想を入れて保存します
- **図鑑**：12か月のマス。その月にいちばん点数の高かった1品の写真が入ります。設定（データの書き出し・読み込み）は図鑑の右上にあります
- **日記**：日付ごとの記録です。2軒以上回った日は、回った順に店を結んだ小さな地図が付きます

## 月ごとのお題
季節の和菓子が各月4つ（全部で48、[docs/quests.md](docs/quests.md)）と、上生菓子の枠が各月1つです。上生菓子の枠は、その月の題材5つ（全部で60）のどれかを記録で選ぶと埋まります。題材の根拠と出典は [docs/motifs.md](docs/motifs.md) にまとめています。主に京都の和菓子屋の月別の品ぞろえをもとにしているので、地域によってはずれがあります。

## 手元で動かす
```
python -m http.server
```
ブラウザで http://localhost:8000/ を開きます。テストは `node --test` で実行します。

## 構成
- `index.html` / `style.css` / `app.js`：画面
- `logic.js`：集計・判子・お題・距離の計算（DOM に触らない純粋関数）
- `db.js`：IndexedDB の読み書き
- `themes/jonamagashi.js`：月・季節の色・季節の和菓子・上生菓子の題材・別名。アプリ本体はテーマに依存しません
- `tools/build-shops.mjs`：OpenStreetMap（Overpass API）から和菓子屋を集めて `data/shops/` を作る（`node tools/build-shops.mjs`。取得結果は `tools/.cache/` に残り、作り直すときに再利用。取り直すなら `--refresh`）
- `data/shops/`：作った店のデータ（0.5度四方の区画ごとの JSON）。詳しくは [data/README.md](data/README.md)
- `sw.js`：オフライン用のキャッシュ（ファイルを変えたら `VERSION` を上げる）
