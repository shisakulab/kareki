# 月ごとのモチーフ（themes/jonamagashi.js に入れる確定版）

2026-10-10 調べ。主な根拠は甘春堂（京都）の月別の上生菓子ページ https://shop.kanshundo.co.jp/view/category/ct27 〜 ct37（1月=27 … 9月=35、10〜11月=36、12月=37）。
「要確認」は、一次情報では確かめられず、一般に言われているもの。京都の店の例が中心で、関東の店とはずれることがある。
